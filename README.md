### Purpose of repository

Code used to analyze the Hi-C component of snm3C-seq in our preprint.

### Citation

Li TW\*, Langerman J\*, Liu C\*, Sun Y\*, et al. Epigenomic heterogeneity and spatial organization during human reprogramming. *bioRxiv* (2026). [https://doi.org/10.64898/2026.10.15.757424](https://www.biorxiv.org/content/10.64898/2026.10.15.757424v1)

\*These authors contributed equally.

### Website

[https://ucla-igvf-pgp-reprogramming.pages.dev/](https://ucla-igvf-pgp-reprogramming.pages.dev/)

### Versions
- FastHigashi 0.1.1 [https://github.com/ma-compbio/Fast-Higashi](https://github.com/ma-compbio/Fast-Higashi) - used to conduct dimensionality reduction
- scHiCluster 1.3.5 [https://github.com/zhoujt1994/scHiCluster](https://github.com/zhoujt1994/scHiCluster) - used for single-nucleus Hi-C matrix imputation and analysis, including TAD-calling and insulation.
- cooltools 0.5.1 [https://cooltools.readthedocs.io/en/latest/#](https://cooltools.readthedocs.io/en/latest/#) - used to call compartments at pseudobulk level.
- TopDom 0.10.1 [https://github.com/HenrikBengtsson/TopDom](https://github.com/HenrikBengtsson/TopDom) - used to call TADs at pseudobulk level.
