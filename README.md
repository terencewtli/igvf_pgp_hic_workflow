### Purpose of repository

Code used to analyze the Hi-C component of snm3C-seq in Li et al. 2026.

Versions:
- FastHigashi 0.1.1 [https://github.com/ma-compbio/Fast-Higashi](url) - used to conduct dimensionality reduction
- scHiCluster 1.3.5 [https://github.com/zhoujt1994/scHiCluster](url) - used for single-nucleus Hi-C matrix imputation and analysis, including TAD-calling and insulation.
- cooltools 0.5.1 [https://cooltools.readthedocs.io/en/latest/#](url) - used to call compartments at pseudobulk level.
- TopDom 0.10.1 [https://github.com/HenrikBengtsson/TopDom](url) - used to call TADs at pseudobulk level.
